# frontend

React 19 + Vite + Tailwind + shadcn/ui. Stands in for the SMS transport: left column is the
lead's phone, right column is what the platform sees and the lead never does. See the
[root README](../README.md) for the reasoning.

## Layout

- `App.tsx` — the only stateful component; holds the conversation and the id it keeps in
  `localStorage`, so a reload re-fetches rather than starting over.
- `components/LeadPicker.tsx`, `Thread.tsx`, `Inspector.tsx` — the three panes.
- `api.ts` — every call to the backend, one function per endpoint.
- `types.ts` — mirrors `web/Dtos.java` by hand.
- `components/ui/` — generated by shadcn/ui, left as generated.

## Run and test

```bash
docker compose up                          # from the repo root; runs the Vite dev server
pnpm install && pnpm dev                   # bare metal: Node 24 + pnpm, needs the backend on :8080
pnpm lint && pnpm exec tsc -b && pnpm build
```

`tsc -b`, not `--noEmit`: under this project-references layout `--noEmit` checks zero files
and exits 0 regardless. Backend URL comes from `VITE_API_URL`, defaulting to
`http://localhost:8080`.
